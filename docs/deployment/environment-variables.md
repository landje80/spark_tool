# Omgevingsvariabelen

Geheimen worden **alleen** in Plesk (Websites & Domains → Node.js → _Custom environment variables_) of in een lokaal, niet-gecommit `.env` gezet. Nooit in Git. `npm run deploy:check` controleert of de verplichte variabelen aanwezig zijn (zonder waarden te tonen); de applicatie valideert ze bij het opstarten met Zod en faalt snel.

Kolom **Waar**: _Plesk_ = Node.js-instellingen van de app · _lokaal_ = alleen `.env` op de ontwikkelmachine.

## Verificatie na instellen

1. `npm run deploy:check` → verplichte variabelen aanwezig.
2. `npm run healthcheck` → `GET /tool/health` geeft `{"status":"ok"}`.
3. Als beheerder: **Instellingen → Integraties** toont per integratie alleen _ingesteld/niet ingesteld_, nooit de waarde.
4. Leadgeneratie: pas als `ANTHROPIC_API_KEY` én `ANTHROPIC_MODEL_LEAD_RESEARCH` bestaan kan de schakelaar zinvol worden aangezet.
